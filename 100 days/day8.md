# Day 8 - Probability Basics

## Overview

Today I learned the fundamentals of probability, one of the core mathematical concepts behind Machine Learning, Deep Learning, and Large Language Models.

---

## What is Probability?

Probability measures the likelihood that an event will occur.

Formula:

P(Event) = Number of Favorable Outcomes / Total Number of Possible Outcomes

Example:

Probability of getting a 6 on a fair die:

P(6) = 1/6

---

## Conditional Probability

Conditional probability calculates the likelihood of an event occurring given that another event has already occurred.

Formula:

P(A|B) = P(A and B) / P(B)

Applications:

* Spam detection
* Medical diagnosis
* Recommendation systems

---

## Bayes' Theorem

Bayes' Theorem helps update probabilities when new information becomes available.

Formula:

P(A|B) = [P(B|A) × P(A)] / P(B)

Applications:

* Machine Learning
* Fraud detection
* Classification problems

---

## Probability Distributions

A probability distribution describes how values are distributed.

Common distributions:

### Normal Distribution

* Bell-shaped curve
* Common in real-world datasets

### Uniform Distribution

* Every outcome has equal probability

### Bernoulli Distribution

* Only two outcomes
* Success or failure

---

## Random Variables

A random variable represents a numerical outcome of a random process.

Examples:

* Dice roll
* Coin toss
* Daily website visitors

---

## Probability in AI

Modern AI systems use probability to:

* Predict outputs
* Rank possible responses
* Estimate uncertainty
* Generate text

Large Language Models predict the most probable next token based on learned patterns.

---

## Key Takeaways

* Probability is fundamental to AI and Machine Learning.
* Bayes' Theorem updates beliefs using new evidence.
* Probability distributions help model real-world data.
* LLMs generate responses using probability-based predictions.
* Strong probability knowledge improves understanding of AI systems.
