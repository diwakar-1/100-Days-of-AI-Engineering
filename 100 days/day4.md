# Day 4 - Dev Tooling: Git, Environments, and Containers

## Overview

Today I learned about the development tools that are commonly used by AI Engineers and Software Developers to manage projects, dependencies, and deployment environments.

---

## Git

Git is a distributed version control system used to track changes in code.

### Benefits

* Tracks project history
* Enables collaboration
* Supports branching and merging
* Helps recover previous versions

### Common Commands

```bash
git init
git add .
git commit -m "Initial Commit"
git push origin main
```

---

## GitHub

GitHub is a cloud platform for hosting Git repositories.

### Uses

* Code hosting
* Team collaboration
* Pull requests
* Issue tracking
* Open-source contributions

---

## Python Virtual Environments

Virtual environments allow projects to maintain isolated dependencies.

### Benefits

* Avoid package conflicts
* Project-specific dependencies
* Better reproducibility

### Commands

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

---

## Containers

Containers package applications along with their dependencies.

### Benefits

* Consistent execution across environments
* Easy deployment
* Scalability
* Isolation

---

## Docker

Docker is a platform used to create and manage containers.

### Why Docker?

* Simplifies deployment
* Ensures consistency
* Works across different operating systems
* Widely used in AI and cloud applications

---

## Key Takeaways

* Git is essential for version control.
* GitHub improves collaboration and project management.
* Virtual environments prevent dependency conflicts.
* Containers improve portability and deployment.
* Docker is an important tool for modern AI Engineering.
