## What I Learned

### What is AI Engineering?

AI Engineering focuses on designing, building, deploying, and maintaining AI-powered applications. It combines software engineering practices with machine learning and AI technologies.

### Key Components

1. Data Collection
2. Model Development
3. Prompt Engineering
4. Application Development
5. Deployment
6. Monitoring and Improvement

### Large Language Models (LLMs)

LLMs are advanced AI models trained on large amounts of text data. They can perform tasks such as:

* Text Generation
* Question Answering
* Summarization
* Translation
* Coding Assistance

### AI Engineering vs Machine Learning

| AI Engineering             | Machine Learning            |
| -------------------------- | --------------------------- |
| Focuses on AI applications | Focuses on model creation   |
| Product-oriented           | Research-oriented           |
| Deployment and scalability | Model accuracy and training |
