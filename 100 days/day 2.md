## What is a Neural Network?

A Neural Network is a computational model inspired by the human brain. It consists of interconnected nodes (neurons) that process information and learn patterns from data.

## Components of a Neural Network

### 1. Input Layer

Receives data from the outside world.

### 2. Hidden Layers

Perform computations and feature extraction.

### 3. Output Layer

Produces the final prediction or result.

### 4. Weights

Determine the importance of inputs.

### 5. Bias

Helps improve model flexibility.

### 6. Activation Function

Introduces non-linearity into the network.

Examples:

* ReLU
* Sigmoid
* Tanh

## Learning Process

### Forward Propagation

Data moves from input to output through the network.

### Backpropagation

Errors are calculated and weights are adjusted to improve performance.

## Applications

* Image Recognition

## Key Takeaways

* Neural Networks are the foundation of Deep Learning.
* Weights and biases help models learn patterns.

* Backpropagation is essential for training.
